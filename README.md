# CS 165: Data Systems

This is my source code for a functional database I made in Fall 2024. It's a performance-optimized multithreaded column-store database in C that supports numerical range queries, aggregates, filters, primary indexes (B+ tree and sorted), secondary indexes (B+ tree and sorted), bulk CSV loading, and joins (Grace hash, simple hash, and nested loop). There's also a database server, DSL parser, durable JSON catalogue, and persistent storage.
